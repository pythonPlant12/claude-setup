# Sources

Collected on 2026-11-11 from:

- LinkedIn activity of Zander Whitehurst (Founder & CEO, Memorisely),
  https://www.linkedin.com/in/zanderwhitehurst/ — about 337 posts covering
  roughly two years. About 160 posts contain UI or design-system advice; the
  rest are career and industry commentary.

Many posts are videos or carousels. Only the text captions were read, so the
skill states the principle from the caption and fills the detail with common
practice. Exact numbers that appear only inside the media (for example the
"70/60 dark mode rule" and the "4-step gradient framework") are not
reproduced.
